# DeepSeek Desktop

DeepSeek Harness 的 Windows x64 桌面安装包社区发行项目。

安装后会在名为 `DeepSeek Desktop` 的内置 WebView 窗口中运行，不会打开外部浏览器。每次启动都会明确选择使用 Groq 免费模型或 DeepSeek API：Groq 默认提供 GPT-OSS 20B，并可在应用内的模型设置中切换 GPT-OSS 120B、Qwen3.6 27B；密钥由用户自行在应用内配置，不会随安装包附带。

发布页提供标准安装包和完整离线安装包，并为每个文件附带 SHA-256 校验值。

构建、验证和安装行为请阅读 [Windows 安装包说明](distribution/windows/README.zh.md)。

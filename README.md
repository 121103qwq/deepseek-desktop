# DeepSeek Desktop

DeepSeek Harness 的 Windows x64 桌面安装包社区发行项目。

安装后会在名为 `DeepSeek Desktop` 的内置 WebView 窗口中运行，不会打开外部浏览器。安装向导会一次性选择使用 Kilo 匿名免费模型或 DeepSeek API：默认的 Kilo Auto Free 不需要登录或 API Key，并可在应用内切换其他 Kilo 免费模型；DeepSeek API 模式由用户自行在应用内配置密钥。后续启动不会重复询问。

发布页提供标准安装包和完整离线安装包。

构建、验证和安装行为请阅读 [Windows 安装包说明](distribution/windows/README.zh.md)。

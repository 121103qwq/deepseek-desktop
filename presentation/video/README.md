# DeepSeek Desktop 演讲视频

这是 DeepSeek Desktop v0.1.0 中文介绍视频的 Remotion 源项目。视频素材来自正式 Windows 安装包的实机测试截图。

```powershell
npm install
npm run preview
npm run still
npm run render
```

成片写入 [`out/deepseek-desktop-v0.1.0-zh.mp4`](out/deepseek-desktop-v0.1.0-zh.mp4)。旁白由 Windows 中文语音 `Microsoft Huihui Desktop` 生成；当前成片为 1920×1080、30 fps、H.264/AAC，时长 62 秒。
